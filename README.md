## Como adicionar uma apresentação

1. Crie uma pasta com o nome `AAAA-MM-DD-evento-cidade`.
2. Exporte os slides do Figma em PDF com o nome `slides.pdf`.
3. Escreva um `README.md` com data, local, público, quem apresentou, número de slides e o link do Figma.
4. Acrescente uma linha na tabela acima.
